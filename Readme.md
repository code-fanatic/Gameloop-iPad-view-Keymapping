## ⬇️ How to get iPad View .. *(Automatic Method)*:
- Completely close Gameloop if running.
- Open this file [iPad-View-(Code-Fanatic).bat](https://github.com/code-fanatic/Gameloop-iPad-view-Keymapping/raw/refs/heads/main/iPad-View-(Code-Fanatic).bat)
- Follow the Steps in this file
- Download these resources in Game: `Lobby HD Resource Pack`, `Erangel HD Resource Pack`, `HD Resource Pack`, `HD Icons`.
- Restart PUBG Mobile.
- Enjoy iPad View 😀

## ⬇️ How to get iPad View .. *(Manual Method)*:
- Completely close Gameloop if running.
- Open `Run` and Paste this 👇 and click Enter : 
```js
%USERPROFILE%\AppData\Roaming\AndroidTbox
```
- Replace your `TVM_100.xml` file with [this](https://github.com/code-fanatic/Gameloop-iPad-view-Keymapping/releases/latest/download/TVM_100.xml) file.
- Download these resources in Game: `Lobby HD Resource Pack`, `Erangel HD Resource Pack`, `HD Resource Pack`, `HD Icons`.
- Restart PUBG Mobile.
- Enjoy iPad View :)
